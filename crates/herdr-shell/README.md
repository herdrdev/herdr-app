# herdr-shell

Herdr's QuickJS mod runtime and GPUI bridge.

## Provenance and maintenance

This crate originated from upstream [`gpui-kit`](https://github.com/longbridge/gpui-kit)
`crates/shell` at commit `1ccf011`, plus Herdr's changes.

From this point on, `herdr-shell` is Herdr's own code rather than a vendored copy kept in
sync with upstream. Upstream improvements are ported by behavior rather than merged.
